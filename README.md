# Aml-and-transaction-monitoring
Using Python, SQL, Excel, and Power BI. The project involves data cleaning, exploratory data analysis (EDA), customer risk assessment, transaction analysis, and alert monitoring to identify unusual transaction patterns and support risk-based decision-making in banking.

## Objective
Analyze synthetic banking transactions to identify potentially unusual activity, customer risk patterns and monitoring alerts.

## Tools
Excel → MySQL → Python/Pandas → Power BI

## Synthetic dataset
- 2,000 customers
- 2,400 accounts
- 20,000 transactions
- Rule-generated alerts
- Country risk reference
- KYC expectation data

## Demo monitoring rules
- High-value transaction
- False positive 
- High-risk country
- High-risk customer

- Risk bands: 0–25 Low, 26–39 Medium, above 40 High.
